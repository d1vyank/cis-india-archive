A total of 7800 websites listed on the Government of India directory were researched upon. url: /accessibility/accessibility-audit-of-govt-websites/ original_url: https://cis-india.org/accessibility/accessibility-audit-of-govt-websites type: blog program: accessibility categories: - Accessibility ---

Two data sets were considered to evaluate the websites. The first data set comprises the errors identified by the automated tool AChecker. These errors are (known errors, likely errors, probable errors, HTML validation errors and CSS validation errors). The second data set was arrived at through manual evaluation. This includes (alternate text for non-text objects, colour change option, navigation markup and form accessibility).
