Training in the use of eSpeak with NVDA

Training in the use of Open Source Screen readers like NVDA will be a focal element of the event. As NVDA with the help of eSpeak provides support for eight Indian languages it will be promoted as a reading tool. The aim of the training is as follows:

  • The candidate should be able to read e-text using NVDA and eSpeak in any one of the eight Indian languages currently supported.
  • The candidate should be able to download accessible content from the various platforms and repositories of accessible material.
  • The candidate should be able to use computers as a knowledge searching tool.
  • The candidate should be able to type using either phonetic, In script or traditional keyboards.

The training will be provided by experts from CIS and DFI.

Who will benefit?

The event is targeted at promoting the use of eSpeak with NVDA amongst senior computer teachers for persons with visual impairment.
