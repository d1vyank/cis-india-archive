This tool presents lexicographical data in tabular format generated from SPARQL queries or from manual lists. Users can switch whether to work on lexeme proper, sense or form and add or modify statements there.

The idea of this tool was inspired by the one and only Magnus Manske's Tabernacle which helps editors to add or modify statements, labels, descriptions and aliases for Wikidata's entity data.

The tool is going to be documented here. Users of this tool can request for more features or report for bugs using this phabricator project profile.

Happy editing!
