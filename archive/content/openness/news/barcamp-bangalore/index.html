Dissecting Wikipedia

Wikipedia is the world’s most famous free and open encyclopaedia which anyone can edit. In this session we will explore various technical aspects of Wikipedia with demonstrations. Wikipedia has its own set of APIs using which we can retrieve information by using various queris and parameters. The output can be generated in various formats. These output can be used for processing by programming languages as input. These will be demonstrated.
