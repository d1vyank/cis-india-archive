Introduction to the course

Rajesh and Anand are offering a course titled Thinking with Data at NIAS. It’ll be covered in 12 – 14 two-hour sessions. The course will cover the basic ways in which we can use data to enhance our thinking capacities. Click here for more information about the course.

Salient Features

  1. How to think with data and work on interesting problems.
  2. Refresher course in programming using Python and HTML.
  3. Discussions and FAQs with faculty and participants.
  4. Project work.

Timings and Venue

It will be screened every Wednesday, starting from September 12, 2012, from 6.30 p.m. to 8.30 p.m.
Venue: Centre for Internet and Society, Bangalore.

As part of the class, we are also offering a refresher course in Python and HTML

  • Objectives: Introduction to Programming using Python
  • Hardware Requirement: Learners should bring their own laptops
  • Prerequisites: Enthusiasm to learn.
  • Audience Level: Learners with following answers are welcomed.
  1. I’m not too comfortable with programming
  2. I can program, but not that well in Python
  3. I’m good at Python
