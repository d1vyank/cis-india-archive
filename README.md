# cis-india.org static archive

A static archive of blog posts and events from cis-india.org (Centre for Internet and Society, India), rebuilt with Hugo and searchable with Pagefind. This is the proof of concept: a 100-item sample (80 blog posts, 20 events).

## Layout

- `theme/` - Hugo config (`hugo.toml`), layouts, CSS and the hand-written section pages. `preview.toml` switches to `.html` URLs and is only for the claude.ai preview.
- `archive/` - converted content: `content/<original path>/index.html` (cleaned HTML with YAML front matter, at the original URL paths) and `static/files/` (attachments and images). Generated by `tools/convert.py`; committed so that hosting only needs Hugo and Pagefind.
- `sample/` - the sample's `listing.json`, `inventory.json` (metadata, attachments and fetch status) and `convert_report.json` (files still missing).
- `tools/crawl_sample.py OUT` - gentle crawler (one request at a time, 3 s pause, backoff).
- `tools/convert.py CRAWL_DIR SITE_DIR` - turns a crawl into `archive/`-style content.
- `tools/build.sh [extra-config.toml]` - merges `theme/` and `archive/` into `site/`, builds with Hugo 0.140.2 (extended), prunes pagination redirect stubs, indexes with Pagefind 1.3.0. Output: `site/public`.

Raw crawl data (`crawl/`) and build output (`site/`, `bin/`) are not committed.

## Rebuilding the content

```sh
python3 tools/crawl_sample.py crawl            # slow: the live server takes up to ~30 s per page
python3 tools/convert.py crawl "$PWD/archive"
sh tools/build.sh                               # needs hugo (or ./bin/hugo) and node/npx
```

Python dependencies: `requests beautifulsoup4 lxml pyyaml`.

## Deploying on Cloudflare Pages

Workers & Pages -> Create -> Pages -> Connect to Git -> this repository, then:

| Setting | Value |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | `sh tools/build.sh` |
| Build output directory | `site/public` |
| Environment variable | `HUGO_VERSION` = `0.140.2` |
| Environment variable | `NODE_VERSION` = `22` |

Cloudflare's build image installs Hugo from `HUGO_VERSION`; `build.sh` runs Pagefind through `npx`.
