# cis-india.org static archive

A static archive of blog posts and events from cis-india.org (Centre for Internet and Society, India), rebuilt with Hugo and searchable with Pagefind. It covers 3,108 blog posts, 446 events and 2,600 news items, converted from the 2026-11-07 server dump.

## Layout

- `theme/` - Hugo config (`hugo.toml`), layouts, CSS and the hand-written section pages. `preview.toml` switches to `.html` URLs and is only for the claude.ai preview.
- `archive/` - converted content: `content/<original path>/index.html` (cleaned HTML with YAML front matter, at the original URL paths) and `static/files/` (attachments and images). Generated by `tools/convert.py`. Only `content/` is committed; attachments (`static/files/`, 4.2 GB) are hosted on R2, see below.
- `sample/` - the sample's `listing.json`, `inventory.json` (metadata, attachments and fetch status) and `convert_report.json` (files still missing).
- `tools/crawl_sample.py OUT` - gentle crawler (one request at a time, 3 s pause, backoff).
- `tools/convert.py CRAWL_DIR SITE_DIR` - turns a crawl into `archive/`-style content.
- `tools/build.sh [extra-config.toml]` - merges `theme/` and `archive/` into `site/`, builds with Hugo 0.140.2 (extended), prunes pagination redirect stubs, indexes with Pagefind 1.3.0. Output: `site/public`.

Raw crawl data (`crawl/`) and build output (`site/`, `bin/`) are not committed.

## Building the full archive from the server dump

The 2026-11-07 dump (`cis-india-archive-2026-11-07.zip`, 6.9 GB, from https://archive.cis-india.org/download/) is a rendered copy of the whole site: `site/<path>/index.html` for every page, attachments as files, and `nginx/files.map` / `redirects.map` mapping URLs to files. No crawling is needed.

```sh
unzip -q cis-india-archive-2026-11-07.zip -d dump
python3 tools/inventory_dump.py dump/cis-india-archive-2026-11-07 work/inventory.json   # ~40 s
python3 tools/convert.py work/inventory.json work/archive                              # ~2 min, writes work/convert_report.json
ARCHIVE=$PWD/work/archive sh tools/build.sh                                            # ~1 min
```

`inventory_dump.py` picks pages by Plone type (`--types blog-entry,event,news-item`, all three by default), keeps one copy of pages reachable under two paths (e.g. `/website/...`), and skips folder pages. The 2026-11-07 dump gives 3,108 blog posts, 446 events and 2,600 news items, with 3,817 attachments (4.2 GB). The built site is about 18,600 files.

Every item keeps its original URL exactly (front matter `url`), including capitals and spaces. Links to pages outside the archive go to `LINK_BASE` (default `https://cis-india.org`); set `FILES_BASE` to serve attachments from another host, such as an R2 bucket.

## Rebuilding the sample from a crawl

```sh
python3 tools/crawl_sample.py crawl            # slow: the live server takes up to ~30 s per page
python3 tools/convert.py crawl "$PWD/archive"
sh tools/build.sh                               # needs hugo (or ./bin/hugo) and node/npx
```

Python dependencies: `requests beautifulsoup4 lxml pyyaml`.

## Deploying: Cloudflare Pages (pages) + R2 (attachments)

`archive/content/` (the converted text of all 6,154 items) is committed; the 4.2 GB of attachments are not. They go to an R2 bucket, and the site redirects `/files/*` there. The Pages build is about 14,800 files / 180 MB.

### 1. R2 bucket for attachments
1. Cloudflare dashboard -> R2 -> Create bucket, e.g. `cis-archive-files`.
2. Bucket -> Settings -> Public access -> Custom domains -> Connect domain, e.g. `files.archive.cis-india.org` (needs the zone on Cloudflare). For a quick test, enable the `r2.dev` URL instead (rate-limited, not for production).
3. R2 -> Manage R2 API tokens -> Create token with Object Read & Write on that bucket. Note the access key ID, secret, and the S3 endpoint `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`.

### 2. Upload the attachments (on a machine with the dump)
```sh
pip install beautifulsoup4 lxml pyyaml           # rclone: https://rclone.org/install/
unzip -q cis-india-archive-2026-11-07.zip -d dump
python3 tools/inventory_dump.py dump/cis-india-archive-2026-11-07 work/inventory.json
python3 tools/convert.py work/inventory.json work/archive
rclone config create r2 s3 provider=Cloudflare access_key_id=KEY secret_access_key=SECRET \
  endpoint=https://ACCOUNT_ID.r2.cloudflarestorage.com acl=private
sh tools/upload_files_r2.sh work/archive cis-archive-files
```
Check one file: `https://files.archive.cis-india.org/files/home-images/costs.jpg`.

### 3. Pages project
Workers & Pages -> Create -> Pages -> Connect to Git -> this repository, then:

| Setting | Value |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | `sh tools/build.sh` |
| Build output directory | `site/public` |
| Environment variable | `HUGO_VERSION` = `0.140.2` |
| Environment variable | `NODE_VERSION` = `22` |
| Environment variable | `FILES_BASE` = `https://files.archive.cis-india.org` (your bucket URL, no trailing slash) |

Then Custom domains -> add e.g. `archive.cis-india.org`.

Cloudflare's build image installs Hugo from `HUGO_VERSION`; `build.sh` runs Pagefind through `npx` and writes `_redirects` for `/files/*` when `FILES_BASE` is set.
